# VapeTochka — каталог

Мобильный каталог вейп-шопа на **Next.js 16 (App Router) + Tailwind CSS 4 + TypeScript**.
База данных — Google Таблица владельца: ассортимент, цены и наличие (✅/❌) редактируются
прямо в таблице, сайт подхватывает изменения сам. Заказ — диплинком в Telegram менеджера.

> Инструкция для владельца магазина (без программирования): **[HOW_TO_UPDATE.md](HOW_TO_UPDATE.md)**

## Возможности

- Mobile-first, тёмная тема с неоновыми акцентами, ощущение нативного приложения
  (липкая шапка с размытием, плавные анимации, safe-area, PWA-манифест).
- Горизонтальная лента категорий = листы таблицы (порядок, скрытие и новые листы — из таблицы).
- Сквозной поиск по всем категориям: бренд, вкус, описание, крепость; не важны регистр и ё,
  понимает неправильную раскладку (`ылфдф` → Skala), транслит (`элфбар` → Elfbar) и синонимы (`лёд` ↔ `ice`).
- Тумблер «Только в наличии» (запоминается на устройстве).
- Карточка: линейка, бренд, крепость, вкус/описание, цена в BYN (и старая цена при скидке),
  индикатор наличия, кнопка «Заказать» → `tg://resolve?domain=VapeTochkaManager&text=…`
  с запасным переходом на `https://t.me/…`, если приложение не установлено.
- Постепенная отрисовка карточек — тысячи позиций не тормозят телефон.

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # заполните переменные (см. HOW_TO_UPDATE.md, шаг 3)
npm run dev                  # http://localhost:3000
```

Без доступа к Google (или с `CATALOG_SOURCE=demo`) в режиме разработки показываются демо-данные
из `src/data/demo-sheets.ts` — это фрагменты реальной таблицы.

| Команда | Что делает |
|---|---|
| `npm run dev` | Режим разработки |
| `npm run build && npm start` | Продакшен-сборка и запуск |
| `npm test` | Юнит-тесты парсера, поиска и ссылок Telegram (Vitest) |
| `npm run lint` / `npm run typecheck` | ESLint / TypeScript |

## Как устроены данные

```
Google Sheets ──► src/lib/sheets/sources.ts   (API v4 batchGet  или  CSV export)
              ──► src/lib/sheets/parse.ts     (строки листа → линейки и позиции)
              ──► src/lib/catalog.ts          ('use cache' + cacheLife 60s + cacheTag)
              ──► src/app/page.tsx            (статическая страница, ISR)
              ──► src/components/Catalog.tsx  (клиент: вкладки, поиск, фильтр)
```

**Источник данных.** Если задан `GOOGLE_API_KEY`, листы берутся через Sheets API v4: один запрос
за списком листов (скрытые и `EXCLUDED_SHEETS` отбрасываются) и один `values:batchGet` за данными.
Без ключа каждый лист из `sheetsConfig.csvTabs` скачивается как CSV по ссылке
`/export?format=csv&gid=…`. В обоих случаях таблица должна быть доступна «всем, у кого есть ссылка».

**Парсер** (`parse.ts`) понимает структуру текущего прайса:

- текст только в колонке A — заголовок линейки; заголовок → пустая строка → заголовок = бренд + линейка
  (бренд сохраняется для следующих линеек до нового бренда);
- текст сразу под заголовком (без пустой строки) — пояснение к линейке;
- `NN BYN` в колонке A — цена для товаров ниже; две цены подряд по убыванию — старая/новая (скидка);
- строка с данными в колонках B+ — позиция; последняя ячейка с ✅/❌ (или «есть»/«нет») — наличие,
  остальные ячейки — название и вариант (сопротивление и т.п.); пустое название = как строкой выше;
- эмодзи в начале названия и описание после « - » / «—» выделяются отдельно;
- крепость (`20mg`, `5%`) извлекается из названия линейки;
- объявления («ВНИМАНИЕ…», «Для заказа @…») и одиночные ✅/❌ в колонке A пропускаются.

**Кэш и обновление.** `getCatalog()` помечен `'use cache'` с `cacheLife({ revalidate: 60 })`:
страница отдаётся статикой, а таблица перечитывается в фоне не чаще раза в минуту
(stale-while-revalidate). Если Google недоступен, в продакшене функция падает и Next.js
продолжает отдавать последнюю удачную версию. Для мгновенного обновления есть
`/api/revalidate` (GET/POST, секрет в `x-revalidate-secret` или `?secret=`), который вызывает
`revalidateTag('catalog', { expire: 0 })`; его дёргает Apps Script-триггер из
`google-apps-script/auto-update.gs`.

## Структура

```
src/
  app/
    layout.tsx, page.tsx, loading.tsx, error.tsx, globals.css
    manifest.ts, icon.svg, apple-icon.tsx      PWA / иконки
    api/revalidate/route.ts                    вебхук мгновенного обновления
  components/
    Catalog.tsx        состояние каталога: вкладки, поиск, фильтр, хэш в URL
    CategoryTabs.tsx   лента категорий
    SearchBar.tsx      поиск
    StockToggle.tsx    тумблер «Только в наличии»
    ProductGrid.tsx    сетка с постепенной подгрузкой
    ProductCard.tsx    карточка товара
    TelegramAnchor.tsx ссылка tg:// с фолбэком на t.me
    EmptyState.tsx, icons.tsx
  config/site.ts       настройки (Telegram, ID таблицы, исключённые листы, CSV-листы, кэш)
  data/demo-sheets.ts  демо-данные (фрагменты реальной таблицы)
  lib/
    sheets/            sources.ts, parse.ts, csv.ts, categories.ts
    catalog.ts         сборка каталога + кэш
    search.ts          нормализация, раскладка, транслит, синонимы
    telegram.ts        тексты и ссылки для заказа
    products.ts, format.ts, hooks.ts, types.ts
google-apps-script/auto-update.gs
HOW_TO_UPDATE.md       инструкция для владельца
```

## Деплой

Проще всего — [Vercel](https://vercel.com): импортируйте репозиторий, добавьте переменные из
`.env.example` в *Settings → Environment Variables* и нажмите Deploy. Работает и на любом
Node.js-хостинге (`npm run build && npm start`).

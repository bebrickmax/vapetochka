# VapeTochka — каталог

Мобильный каталог вейп-шопа на **Next.js 16 (App Router) + Tailwind CSS 4 + TypeScript**.
База данных — Google Таблицы владельца (у каждой точки продаж своя): ассортимент, фото, цены
и наличие (✅/❌) редактируются прямо в таблице, сайт подхватывает изменения сам.
Заказ — диплинком в Telegram менеджера.

> Инструкция для владельца магазина (без программирования): **[HOW_TO_UPDATE.md](HOW_TO_UPDATE.md)**

## Возможности

- Монохромный дизайн под логотип (векторизован в `src/config/logo.ts`): чёрный фон, белые
  «этикетки» с фото товара, широкий шрифт Unbounded для названий и цен; PWA-иконки из знака логотипа.
- Две точки продаж (`src/config/stores.ts`): экран выбора на `/`, каталоги на `/main` и
  `/kamennaya-gorka`, выбор запоминается, переключатель в шапке, у каждой точки своя корзина
  и свой способ получения (основной склад — метро/самовывоз/доставка, Каменная Горка — самовывоз).
- Горизонтальная лента категорий = листы таблицы (порядок и новые листы — из таблицы),
  под ней — бренды категории (`src/lib/brands.ts`: бренд из таблицы или общее начало названий).
- Карточка линейки, как в таблице: фото (картинка из ячейки колонки A), бренд, крепость, цена,
  «N из M в наличии» и список вкусов/моделей с кнопками «+»; длинные списки сворачиваются.
- Сквозной поиск по всем категориям: бренд, вкус, описание, крепость; не важны регистр и ё,
  понимает неправильную раскладку (`ылфдф` → Skala), транслит (`элфбар` → Elfbar) и синонимы (`лёд` ↔ `ice`).
- Тумблер «Только в наличии» (запоминается на устройстве).
- Заказ → `tg://resolve?domain=VapeTochkaManager&text=…` с запасным переходом на `https://t.me/…`,
  если приложение не установлено. Компьютерные приложения Telegram не раскодируют русский текст
  из ссылки («%D0%9D…»), поэтому на компьютере чат открывается без текста, а текст копируется
  в буфер обмена с подсказкой «вставьте его в чат».
- Корзина (сохраняется на устройстве): «В корзину» / «− N +» на карточке, плавающая плашка с суммой,
  панель корзины и оформление заказа (метро / самовывоз / доставка) с проверкой полей. Заказ уходит
  менеджеру готовым текстом в Telegram (текст также копируется в буфер обмена).
  Станции, точки самовывоза и часы менеджера — в `src/config/checkout.ts`.
- Избранное (♡ на карточке, своя вкладка, хранится на устройстве) и «Повторить прошлый заказ»
  в пустой корзине — добавляет то, что сейчас в наличии, со свежими ценами.
- Корзина сверяется с таблицей: id товара — по названию линейки и вкуса, цены свежие,
  закончившиеся позиции помечены и не попадают в заказ.
- Превью ссылки (`opengraph-image.tsx`) с логотипом.
- Вкладка «Акции и ОПТ»: тексты акций в `src/config/promotions.ts`; опт из листа «ОПТ» — разделы,
  бренды, фото и четыре цены по количеству (от 10/30/50/100 шт, `src/lib/sheets/wholesale.ts`).
- Постепенная отрисовка карточек — тысячи позиций не тормозят телефон.

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # заполните переменные (см. HOW_TO_UPDATE.md, шаг 3)
npm run dev                  # http://localhost:3000
```

Без доступа к Google (или с `CATALOG_SOURCE=demo`) в режиме разработки показываются демо-данные
из `src/data/demo-sheets.ts` — это фрагменты реальной таблицы.

| Команда | Что делает |
|---|---|
| `npm run dev` | Режим разработки |
| `npm run build && npm start` | Продакшен-сборка и запуск |
| `npm test` | Юнит-тесты парсера, поиска и ссылок Telegram (Vitest) |
| `npm run lint` / `npm run typecheck` | ESLint / TypeScript |

## Как устроены данные

```
Google Sheets ──► src/lib/sheets/sources.ts   (список листов, данные: API v4 или CSV, фото: htmlview)
              ──► src/lib/sheets/htmlview.ts  (листы и картинки в ячейках из веб-просмотра)
              ──► src/lib/sheets/parse.ts     (строки листа → линейки, позиции, фото)
              ──► src/lib/brands.ts           (бренды-«чипсы» внутри категории)
              ──► src/lib/catalog.ts          ('use cache' + cacheLife 60s + cacheTag, по точке)
              ──► src/app/[store]/page.tsx    (статические страницы точек, ISR)
              ──► src/components/Catalog.tsx  (клиент: вкладки, бренды, поиск, фильтр)
```

**Источник данных.** Если задан `GOOGLE_API_KEY`, листы берутся через Sheets API v4: один запрос
за списком листов (скрытые и `EXCLUDED_SHEETS` отбрасываются) и один `values:batchGet` за данными.
Без ключа список листов читается из `/htmlview` (запасной список — `fallbackTabs` точки), а каждый
лист скачивается как CSV по ссылке `/export?format=csv&gid=…`. Фото в обоих режимах берутся из
`/htmlview/sheet?gid=…` (картинки в ячейках колонки A, номер строки → адрес `sheets-images-rt`,
размер подставляется параметром `=s360`). Таблица должна быть доступна «всем, у кого есть ссылка».

**Парсер** (`parse.ts`) понимает структуру текущего прайса:

- текст только в колонке A — заголовок линейки; заголовок → пустая строка → заголовок = бренд + линейка
  (бренд сохраняется для следующих линеек до нового бренда);
- текст сразу под заголовком (без пустой строки) — пояснение к линейке;
- `NN BYN` в колонке A — цена для товаров ниже; две цены подряд по убыванию — старая/новая (скидка);
- строка с данными в колонках B+ — позиция; последняя ячейка с ✅/❌ (или «есть»/«нет») — наличие,
  остальные ячейки — название и вариант (сопротивление и т.п.); пустое название = как строкой выше;
- эмодзи в начале названия и описание после « - » / «—» выделяются отдельно;
- крепость (`20mg`, `5%`) извлекается из названия линейки;
- объявления («ВНИМАНИЕ…», «Для заказа @…») и одиночные ✅/❌ в колонке A пропускаются.

**Кэш и обновление.** `getCatalog()` помечен `'use cache'` с `cacheLife({ revalidate: 60 })`:
страница отдаётся статикой, а таблица перечитывается в фоне не чаще раза в минуту
(stale-while-revalidate). Если Google недоступен, в продакшене функция падает и Next.js
продолжает отдавать последнюю удачную версию. Для мгновенного обновления есть
`/api/revalidate` (GET/POST, секрет в `x-revalidate-secret` или `?secret=`), который вызывает
`revalidateTag('catalog', { expire: 0 })`; его дёргает Apps Script-триггер из
`google-apps-script/auto-update.gs`.

## Структура

```
src/
  app/
    page.tsx                                   выбор точки (или переход в запомненную)
    [store]/page.tsx                           каталог точки
    layout.tsx, loading.tsx, error.tsx, globals.css
    manifest.ts, icon.svg, apple-icon.tsx      PWA / иконки из знака логотипа
    api/revalidate/route.ts                    вебхук мгновенного обновления
  components/
    Catalog.tsx        состояние каталога: вкладки, бренды, поиск, фильтр, хэш в URL
    StorePicker.tsx    экран выбора точки
    StoreSwitcher.tsx  кнопка точки в шапке
    CategoryTabs.tsx   ленты категорий и брендов
    LineList.tsx       линейки по разделам с постепенной подгрузкой
    LineCard.tsx       карточка линейки со списком позиций
    ProductPhoto.tsx   фото-«этикетка» и просмотр фото
    Promotions.tsx     акции и оптовые цены
    Logo.tsx, SearchBar.tsx, StockToggle.tsx, EmptyState.tsx, TelegramAnchor.tsx, icons.tsx
    cart/              корзина, оформление заказа
  config/
    stores.ts          точки продаж: таблицы, запасные списки листов, способ получения
    site.ts            Telegram, исключённые листы, лист ОПТ, подписи цен опта, кэш
    checkout.ts        метро, точки самовывоза, часы менеджера
    promotions.ts      тексты акций
    logo.ts            векторный логотип
  data/demo-sheets.ts  демо-данные (фрагменты реальной таблицы)
  lib/
    sheets/            sources.ts, htmlview.ts, parse.ts, wholesale.ts, csv.ts, categories.ts
    catalog.ts         сборка каталога + кэш
    brands.ts          бренды внутри категории
    search.ts          нормализация, раскладка, транслит, синонимы
    telegram.ts        тексты и ссылки для заказа
    cart.ts, products.ts, store-choice.ts, format.ts, hooks.ts, types.ts
google-apps-script/auto-update.gs
HOW_TO_UPDATE.md       инструкция для владельца
```

## Деплой

Проще всего — [Vercel](https://vercel.com): импортируйте репозиторий, добавьте переменные из
`.env.example` в *Settings → Environment Variables* и нажмите Deploy. Работает и на любом
Node.js-хостинге (`npm run build && npm start`).

# Telegram-бот: каталог прямо в Telegram

Бот присылает приветствие с кнопками точек. Нажатие открывает каталог сайта прямо внутри Telegram
(Mini App): поиск, фото, корзина. Слева от поля ввода у бота — кнопка «Каталог».

Заказ из корзины в Telegram:
- если задан чат для заказов — бот сразу присылает заказ туда (с именем покупателя и ссылкой на него),
  а покупателю — подтверждение;
- если не задан — открывается чат с менеджером с готовым текстом, как на сайте.

## Подключить (≈5 минут)

1. В Telegram откройте **@BotFather** → `/newbot` → название (например, «Vape Точка») → адрес бота,
   оканчивающийся на `bot` (например, `vapetochka_bot`). BotFather пришлёт **токен** вида `123456:ABC…`.
   Никому его не пересылайте.
2. **Vercel** → проект → Settings → Environment Variables → `TELEGRAM_BOT_TOKEN` = токен (Production) → Save →
   Deployments → ⋯ → **Redeploy**.
3. Подождите до 10 минут — бот сам подключится к сайту при ближайшем автообновлении. Сразу —
   откройте `https://vapetochka.vercel.app/api/telegram?secret=ВАШ_REVALIDATE_SECRET`
   (ответ «Бот подключён к сайту»).
4. Откройте своего бота → «Старт» — придут кнопки точек.

## Заказы в рабочий чат (по желанию)

1. Добавьте бота в рабочую группу (или напишите боту сами, если заказы должны приходить вам лично).
2. Отправьте в этот чат команду `/id` — бот ответит числом (у групп оно начинается с `-100`).
3. Vercel → `TELEGRAM_ORDERS_CHAT_ID` = это число → Save → Redeploy.

Проверка: откройте каталог через бота, положите что-нибудь в корзину → «Отправить заказ» → заказ появится
в рабочем чате, а в чате с ботом — подтверждение.

## Как устроено

| Путь | Что делает |
|---|---|
| `POST /api/telegram` | Вебхук: Telegram присылает сообщения боту (проверяется секрет, выведенный из токена) |
| `GET /api/telegram?secret=…` | Подключить бота к сайту сразу (вебхук, кнопка «Каталог», команды, описание) |
| `POST /api/telegram/order` | Заказ из корзины в Telegram: подпись данных Telegram проверяется на сервере |

Скрипт Telegram подгружается только когда сайт открыт из бота — обычным посетителям он не мешает.
